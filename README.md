### **1️⃣ Назначение файла (по смыслу кода)**

Файл `main.py` представляет собой **основной исполняемый скрипт телеграм-бота**, предназначенного для **регистрации пользователей на веб-сайте "Store21"**.  
Бот взаимодействует с пользователем через чат в Telegram:  
- Запрашивает логин,  
- Предлагает выбрать длину пароля (6/8/10 символов),  
- Генерирует случайный пароль,  
- Сохраняет логин и пароль в базу данных PostgreSQL,  
- Уведомляет пользователя об успешной регистрации.  

Файл реализует **простой FSM-подобный поток регистрации** с использованием `telebot` и `psycopg2`, без использования внешних фреймворков (например, `aiogram` или `django`).  
Это **точка входа** в бота — запускается через `bot.polling()`.

### **2️⃣ Таблица: Имена, типы, назначения и взаимодействия**

| Имя | Тип | Назначение | Взаимодействия |
|-----|-----|------------|----------------|
| `TOKEN` | Переменная | Токен доступа к Telegram Bot API (пустой — потенциальная уязвимость) | Используется в `telebot.TeleBot(TOKEN)` для инициализации бота. |
| `bot` | Переменная (объект) | Экземпляр Telegram-бота, созданный через `telebot.TeleBot` | Используется для отправки сообщений, регистрации обработчиков, запуска опроса. |
| `chars` | Переменная (строка) | Набор символов для генерации случайных паролей | Используется в `generate_password()` для выбора случайных символов. |
| `user_data` | Переменная (словарь) | Глобальный кэш для временного хранения данных пользователей (логин → chat_id) | Используется в `create_login()` для сохранения логина и в `callback_password_length()` для извлечения его при генерации пароля. |
| `create_login(message)` | Функция | Обработчик ввода логина пользователя после команды `/start` | Вызывается `bot.register_next_step_handler()`; сохраняет логин в `user_data` и вызывает `password_length_markup()`. |

| `generate_password(length)` | Функция | Генерирует случайный пароль заданной длины из `chars` | Вызывается в `callback_password_length()` для создания пароля. |
